# 网盘离线下载助手

一个浏览器拓展，能够识别网页上的磁力链接，并新增保存按钮，快捷发起离线下载到支持的网盘中。并提供批量离线下载的功能。

# 支持的网盘列表
- 123云盘
- PikPak网盘

# 功能
## 识别网页上的磁力链接
在网页的磁力链接后面，新增离线按钮，快捷发起网盘内的离线下载。
 ![项目截图](.img/readme/1.png)
## 批量离线下载
在点击拓展的弹窗中，输入下载链接列表（每行一个），可以批量离线下载。
 ![项目截图](.img/readme/2.png)
## 设置默认保存文件夹
在设置中，可以设置默认需要保存的文件夹ID。可以从网页连接中查看具体的文件夹ID。
 ![项目截图](.img/readme/3.png)

# 使用方法
1. 下载安装该浏览器拓展。
2. 在同一个浏览器实例，打开并登录网盘。
3. 在设置中，点击同步Token。
4. 同步成功后，可以正常使用功能。
